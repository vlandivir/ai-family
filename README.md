# ai-family

Семейный бот и общая очередь. Бот работает через уже оплаченную подписку Cursor. Отдельный счёт OpenAI или Anthropic не заводим.

Репозиторий публичный. Здесь воркер, очередь и настройки тем. Секретов в git нет. Семейный проект — отдельный репозиторий с префиксом `ai-family-`.

Семья пишет боту в Telegram. Сейчас две темы. Квартиры в Белграде: правила и витрина в приватном `vlandivir/ai-family-belgrade-apartments`, карточки смотрят по секретной ссылке. Сербский: наставник переводит с русского и обратно, отвечает на вопросы и подсказывает более разговорную формулировку, правила в публичном `vlandivir/ai-family-serbian`.

## Статус

Воркер запущен на Hetzner. Сообщения из Telegram разбирает Cursor CLI. Карточки и диалоги пишутся в Supabase во Франкфурте. Фото лежат в Hetzner Object Storage. Витрина Белграда открыта на Vercel.
