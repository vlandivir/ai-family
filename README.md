# ai-family

Семейный сайт с несколькими проектами и общим чат-ботом. Бот работает через уже оплаченную подписку Cursor или Claude. Отдельный счёт OpenAI или Anthropic не заводим.

Репозиторий публичный. Сейчас здесь только договорённости. Кода приложения, деплоя и секретов нет, и секретам здесь не место. Семейные проекты лежат в отдельных репозиториях.
