# Агенты

Перед каждым `git commit` обнови дневник разработчика. Это относится к любому агенту: Cursor, Claude, Codex и остальным. Проверку делает git-хук `.githooks/pre-commit`, не среда агента.

Один день — один файл `dev-diary/YYYY-MM-DD.md` (локальная дата). Перепиши файл целиком списком того, что уже сделано. Каждый пункт начинается с глагола. Не пиши планы и не дописывай пункты к старому списку. Без секретов.

1. `git add` файлов коммита, без папки `dev-diary/`. Это подготовка, не отдельный коммит.
2. Штамп: `.githooks/pre-commit --stamp`
3. Учти коммиты с полуночи и подготовленные файлы. Перепиши `dev-diary/YYYY-MM-DD.md`. Последняя строка: `<!-- dev-diary-stamp: ШТАМП -->`
4. `git add` этого файла и один коммит.

Подробности — в `.cursor/skills/dev-diary/SKILL.md`. Обход одного коммита: `DEV_DIARY_SKIP=1`.

В новом клоне один раз: `git config core.hooksPath .githooks`
