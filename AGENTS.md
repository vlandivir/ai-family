# Агенты

Перед каждым `git commit` обнови дневник разработчика. Это относится к любому агенту: Cursor, Claude, Codex и остальным. Проверку делает git-хук `.githooks/pre-commit`, не среда агента.

Один день — один файл `dev-diary/YYYY-MM-DD.md` (локальная дата). Перепиши файл целиком: одно-три предложения, что изменилось за день и зачем. Не дописывай абзац к старому. Без списка файлов и без секретов.

1. В индекс положи изменения коммита, без папки `dev-diary/`.
2. Штамп: `.githooks/pre-commit --stamp`
3. Учти коммиты с полуночи и текущий индекс. Перепиши `dev-diary/YYYY-MM-DD.md`. Последняя строка: `<!-- dev-diary-stamp: ШТАМП -->`
4. `git add` этого файла и коммит.

Подробности — в `.cursor/skills/dev-diary/SKILL.md`. Обход одного коммита: `DEV_DIARY_SKIP=1`.

В новом клоне один раз: `git config core.hooksPath .githooks`
