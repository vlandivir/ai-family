# Ресурсы

## Что уже используется

- Публичный репозиторий GitHub `vlandivir/ai-family`. Секретов в нём нет. Проекты — в отдельных репозиториях `ai-family-*`.
- Supabase во Франкфурте, план Free. Там очередь, проекты и карточки. Фото в этот Storage не кладём.
- Hetzner Object Storage, бакет фото в Фалькенштайне (`fsn1`). Снаружи бакет закрыт, витрина берёт временную ссылку.
- Подписка Cursor. Ключ `CURSOR_API_KEY` лежит только на машине воркера.
- Vercel Hobby для витрины Белграда. Адрес `*.vercel.app`, отдельный домен не подключён.
- Машина воркера: Hetzner CX23, Ubuntu 24.04, Фалькенштайн. Входящий порт — SSH.

## Машина воркера

- Linux. Сейчас Ubuntu 24.04.
- Исходящий HTTPS до Cursor, Supabase, Telegram, GitHub и бакета фото.
- Node.js 22 и Cursor CLI.
- Секреты только в `/etc/ai-family.env`: ключ Cursor, Telegram, GitHub, Supabase и бакет. На Vercel у витрины свой набор, без ключа бота.

На диске воркера лежат клон репозитория проекта, файлы диалогов и вложения из Telegram. Фото карточек туда не складываются.

## Хостинг витрины

Витрина живёт отдельно от воркера, на Vercel. Каталог открывается, даже когда машина с ботом спит. Пуш в `main` репозитория проекта выкладывает сайт.

Тот же VPS или статический хост остаются возможной заменой. Сейчас витрина на них не перенесена.
