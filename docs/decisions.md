# Решения

Зафиксировано 22 сентября 2026.

## Принято

- Семейный сайт и бот живут в этом репозитории. Обсуждение архитектуры ведём здесь.
- Код приложения пишем позже, отдельным шагом. Секреты в git не кладём.
- Данные, логин, файлы и очередь — Supabase, регион EU. Это обязательно в любой схеме.
- Доступ к строкам — RLS по членству в проекте. Админ назначает, кто какой проект видит.
- Вход в первую версию — Google через Supabase Auth. Первый админ — allowlist email владельца.
- Яндекс — позже, отдельным OIDC-провайдером.
- Один Next.js-приложение и один репозиторий. Проекты — маршруты и свои таблицы, не отдельные деплои.
- Бот тратит уже оплаченную подписку. Отдельный счёт OpenAI или Anthropic не заводим.
- Первый адаптер бота — Cursor SDK, local runtime, ключ `CURSOR_API_KEY`.
- Второй адаптер, когда понадобится — Claude Code CLI с токеном подписки. Флаг `--bare` не используем.
- ChatGPT Plus в первую версию не входит.
- Воркер — отдельный Linux-процесс. Входящие порты не открываем: он сам опрашивает очередь.
- Один прогон бота за раз.
- Сайт можно поставить на Vercel, на тот же VPS, что и воркер, или на статический хост. На очередь и адаптер это не влияет.
- Рабочая связка на старте, пока место воркера не выбрано: сайт на Vercel, воркер отдельно.

## Открыто

- Где физически стоит воркер: уже имеющийся компьютер, домашняя коробка или маленький VPS в EU.
- Останется ли сайт на Vercel или переедет на VPS вместе с воркером.
- Когда переходить с Supabase Free на Pro. Повод — фото: на бесплатном плане Storage около 1 ГБ.
